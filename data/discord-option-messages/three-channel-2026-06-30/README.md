# Three-Channel Discord Option Messages

This folder stores the raw Discord option-analysis messages captured from the PA,
QMR, and MR channels for the three-channel consensus analysis.

- `three-channel-history.json`: raw captured Discord messages and embed payloads.
- `manifest.json`: channel coverage, source URLs, file size, and SHA256 checksum.

Runtime logs, OpenD minute-bar caches, and backtest outputs are intentionally not
included here.
